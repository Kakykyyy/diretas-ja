# Diretas Já — A voz de um povo

Site educativo

Site publicado — https://diretas-ja.vercel.app

## Abrir o projeto

Abra a pasta no VS Code e abra `index.html` no navegador, ou use a extensão Live Server. O projeto usa HTML, CSS e JavaScript e dispensa instalação de dependências.

## Organização

- `index.html` contém a estrutura e o conteúdo dos capítulos.
- `style.css` contém cores, tipografia, layouts responsivos e animações.
- `site.js` contém os dados da linha do tempo, personagens, quiz e slides, além das interações.
- `assets/` contém as fotografias utilizadas.
- `vercel.json` configura a publicação estática.

## Apresentação

Use o botão “Iniciar apresentação”. As setas navegam pelos slides e Esc encerra a apresentação. O quiz inclui dez perguntas, explicações e pontuação final.

## Fotografias e referências

Os créditos e links das fontes estão disponíveis no site. As fotografias pertencem aos respectivos autores e acervos, com condições de reutilização próprias.
